# Rollen- und Rechtekonzept

| Rolle | Rechte |
| --- | --- |
| user | Eigenes Profil, eigene Dokumente, eigene Freigaben verwalten |
| verifier | Eingereichte Examen und Nachweise prüfen |
| admin | Nutzer ansehen, sperren/entsperren, Prüfungen und Audit-Logs sehen |
| superadmin | Rollen vergeben und Systemeinstellungen verwalten |
