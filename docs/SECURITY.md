# Security

- Private Dateien nie direkt öffentlich ausliefern.
- Signed URLs kurz halten.
- Admin- und Verifier-Zugriffe über RLS und Rollen absichern.
- Keine sensiblen Notizen oder Admin-Kommentare im Public RPC ausgeben.
- CSP vor Produktivbetrieb ergänzen und Upload-Malware-Scanning einplanen.
